# 💰 FinanFit

사용자의 **나이, 투자성향, 직업, 소득 정보**를 기반으로 금융상품을 추천하고,  
OpenAI API를 활용한 금융상품 상담 챗봇을 제공하는 **개인 맞춤형 금융상품 추천 웹 서비스**입니다.

사용자는 회원가입 후 자신의 정보를 등록할 수 있으며, 등록된 사용자 정보와 금융상품 데이터를 분석하여 적합도가 높은 예금상품을 추천받을 수 있습니다.

# 📖 프로젝트 소개

**FinanFit**은 사용자의 개인 정보를 바탕으로 금융상품을 추천하는 웹 애플리케이션입니다.

회원가입 시 입력한 다음 정보를 금융상품 추천에 활용합니다.

- 나이
- 투자성향
- 직업
- 연소득

금융상품 데이터는 CSV 파일에서 불러오며, 상품의 금리, 가입기간, 가입금액, 가입방법 등의 정보를 사용자 정보와 비교하여 추천 점수를 계산합니다.

또한 OpenAI의 `gpt-4o-mini` 모델을 이용하여 사용자가 추천된 금융상품에 대해 질문할 수 있는 금융상담 챗봇 기능을 제공합니다.

# ⚙ 주요 기능

## 1. 회원가입

사용자는 다음 정보를 입력하여 회원가입할 수 있습니다.

- 아이디
- 비밀번호
- 이름
- 이메일
- 나이
- 성별
- 투자성향
- 직업
- 연소득
- 프로필 이미지

회원정보는 SQLite 데이터베이스에 저장됩니다.

비밀번호는 평문으로 저장하지 않고 `PBKDF2-HMAC-SHA256` 방식으로 해싱하여 저장합니다.

---

## 2. 로그인 / 로그아웃

SQLite에 저장된 회원정보를 이용하여 로그인합니다.

로그인 성공 시 Session을 이용해 로그인 상태를 유지하며, 로그인하지 않은 사용자가 메인 화면이나 챗봇에 접근하면 로그인 페이지로 이동합니다.

---

## 3. 사용자 맞춤 금융상품 추천

회원가입 시 등록한 다음 정보를 활용합니다.

```text
나이
투자성향
직업
연소득
```

금융상품 CSV에 저장된 다음 정보와 비교하여 상품별 추천 점수를 계산합니다.

```text
금융사
상품명
최고금리
기본금리
가입기간
가입금액
가입방법
가입대상
```

점수가 높은 금융상품 중 상위 **3개 상품**을 메인 화면에 표시합니다.

---

## 4. 금융상품 상세 정보

추천 상품 카드에서는 다음 정보를 확인할 수 있습니다.

- 금융사
- 상품명
- 최고금리
- 기본금리
- 가입기간
- 가입금액
- 가입방법
- 가입대상
- 금융상품 상세 URL

---

## 5. AI 금융상품 상담 챗봇

OpenAI의 `gpt-4o-mini` 모델을 이용한 금융상품 상담 기능을 제공합니다.

챗봇은 로그인한 사용자의 다음 정보를 참고합니다.

```text
이름
나이
투자성향
직업
연소득
추천 금융상품
```

따라서 일반적인 챗봇 답변이 아니라 현재 사용자에게 추천된 금융상품을 중심으로 상담할 수 있습니다.

예시 질문:

```text
추천 상품 중 금리가 가장 높은 상품 알려줘
```

```text
가입기간이 짧은 상품은 어떤 거야?
```

```text
내 소득 수준에서 어떤 상품이 적합해?
```

```text
이 상품 가입금액은 얼마야?
```

# 🧠 금융상품 추천 방식

각 금융상품에 대해 점수를 계산한 후 점수가 높은 상품을 추천합니다.

### 금리

기본금리와 최고금리가 높은 상품에 높은 점수를 부여합니다.

### 투자성향

사용자의 투자성향에 따라 금리와 상품 특성에 서로 다른 가중치를 적용합니다.

```text
안정형
안정추구형
위험중립형
적극투자형
공격투자형
```

예를 들어 안정형 사용자는 기본금리가 높은 상품을 상대적으로 우선하며, 적극투자형 또는 공격투자형은 최고금리가 높은 상품에 더 높은 점수를 부여합니다.

### 나이

연령대에 따라 가입기간이나 비대면 가입 가능 여부 등의 요소를 추천 점수에 반영합니다.

### 직업

직장인, 공무원, 자영업자, 사업자, 학생 등의 직업 정보를 금융상품 가입대상 및 가입방법과 비교합니다.

### 소득

사용자의 연소득과 금융상품의 최소 가입금액을 비교하여 부담이 적은 상품에 추가 점수를 부여합니다.

최종적으로 상품별 점수를 정렬하여 상위 상품을 사용자에게 제공합니다.

# 🚀 실행 방법

## 1. 프로젝트 다운로드

```bash
git clone 저장소주소
```

프로젝트 폴더로 이동합니다.

```bash
cd FinanFit
```

---

## 2. 필요한 라이브러리 설치

```bash
pip install fastapi==0.142.2 uvicorn jinja2 python-multipart pandas python-dotenv openai itsdangerous
```

또는 `requirements.txt`가 있는 경우 다음 명령어를 사용할 수 있습니다.

```bash
pip install -r requirements.txt
```

# 🔑 환경 변수 설정

프로젝트 최상위 경로에 `.env` 파일을 생성합니다.

```text
OPENAI_API_KEY=본인의_OPENAI_API_KEY
SESSION_SECRET_KEY=원하는_세션_비밀키
```

예시:

```text
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx
SESSION_SECRET_KEY=my-secret-key
```

> `.env` 파일에는 API Key와 같은 중요한 정보가 포함되어 있으므로 GitHub에 업로드하지 않는 것을 권장합니다.

`.gitignore`에 다음 내용을 추가할 수 있습니다.

```gitignore
.env
users.db
__pycache__/
*.pyc
```

# 🔐 보안 처리

FinanFit에서는 회원 비밀번호를 그대로 데이터베이스에 저장하지 않습니다.

```text
PBKDF2-HMAC
SHA-256
Salt
100,000 Iterations
```

방식을 사용해 비밀번호를 해싱한 후 SQLite 데이터베이스에 저장합니다.

로그인 시 입력한 비밀번호를 동일한 방식으로 계산한 후 저장된 값과 비교합니다.

# 🤖 AI 상담 처리 흐름

```text
사용자 질문
    ↓
로그인 사용자 정보 조회
    ↓
사용자 맞춤 금융상품 5개 추출
    ↓
사용자 정보 + 금융상품 정보를 Prompt에 전달
    ↓
OpenAI gpt-4o-mini
    ↓
금융상품 상담 답변
    ↓
웹 화면 출력
```

챗봇은 CSV에 존재하는 금융상품 정보를 우선하여 답변하도록 구성되어 있으며, 존재하지 않는 금융상품 정보를 임의로 생성하지 않도록 Prompt가 설정되어 있습니다.
